# Security Policy

## Scope

This repository is a public professional profile and portfolio. It may link to or describe separate projects. A vulnerability in a linked project should be reported to that project's maintainers where possible.

## Supported status

This profile repository is maintained as a portfolio and documentation resource. No service-level agreement or guaranteed response time is offered.

## Reporting

Please report suspected vulnerabilities privately through the contact options on the GitHub profile: https://github.com/codefuxion

Include:
- A concise description of the issue.
- The affected repository or component.
- Impact and conditions required to reproduce it.
- A safe proof of concept that does not expose real user data or disrupt systems.

Do not disclose secrets, exploit other users' accounts, or perform testing outside systems for which you have explicit authorization.

## Secret handling

If a secret is accidentally committed, revoke or rotate it immediately. Removing it from the latest commit alone may not remove it from Git history or external caches.
