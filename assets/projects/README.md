# Project Screenshot Guide

The portfolio should use genuine product screenshots, not invented mockups presented as shipped work.

## What to capture

For each project, aim for:
1. A clear landing page or home screen.
2. One representative dashboard or core workflow.
3. One administrative or configuration screen only if it is safe to share.
4. A mobile view when the interface is responsive.

## Before uploading

- Remove names, email addresses, phone numbers and customer records.
- Blur or remove balances, payment references and transaction details.
- Never expose passwords, API keys, access tokens, private URLs or QR codes that grant access.
- Obtain permission before publishing client or partner interfaces.
- Do not imply a planned feature is already implemented.

## Suggested folder structure

```text
assets/
  projects/
    strydo-pay/
    sportsflowsai/
    zentrapays/
    cj-grand-group/
    strydo-technology/
    website-script-marketplace/
```

Use descriptive, lowercase filenames such as `dashboard-desktop.png` and `landing-mobile.png`.

## Add a project image

1. Capture the actual product in a clean browser window.
2. Crop away unrelated browser or desktop content.
3. Redact sensitive information.
4. Add the approved image to the relevant folder.
5. Link it from the matching case study and portfolio card.
6. Include alternative text describing what the screenshot shows.

No project screenshots are included until genuine, approved images are supplied.
