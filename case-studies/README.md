# Project Case Studies

Use the template below for each project that has a demonstrable implementation. Keep product concepts separate from shipped software.

## Case study template

### Project name
**Status:** Concept / Prototype / In development / Live / Maintained  
**Role:** What you personally did  
**Problem:** The user or business problem being addressed  
**Solution:** What was designed or implemented  
**Stack:** Verified languages, frameworks, databases and services  
**Key engineering decisions:** Architecture, integrations, security and trade-offs  
**Evidence:** Screenshots, demo URL, source repository, tests or release notes  
**What I learned:** Outcomes and next improvements

Do not publish private client information, secrets, unsupported performance claims, or unverified user metrics.
