# Engineering Examples

Small, self-contained demonstrations that can be run and reviewed independently.

- [Node.js HTTP API](node-api/README.md) — built-in HTTP server, JSON responses, and Node test runner tests.
- [PHP secure query pattern](php/secure-query.php) — PDO prepared statements and parameter binding.

These examples are educational starting points, not complete production systems. Each real application needs requirements-specific validation, authorization, logging, tests, deployment configuration, and security review.
