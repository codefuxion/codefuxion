# Node.js API Demo

A tiny HTTP API using Node.js built-in modules only. It demonstrates route handling, JSON responses, basic response headers, and automated tests.

## Requirements

- Node.js 20 or newer

## Run

```bash
npm start
```

Open `http://localhost:3000/health` or `http://localhost:3000/api/profile`.

## Test

```bash
npm test
```

This is a learning/demo service, not a production-ready API gateway. Production services need authentication, authorization, rate limiting, input validation, structured logging, monitoring, and deployment-specific hardening.
